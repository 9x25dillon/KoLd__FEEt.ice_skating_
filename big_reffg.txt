1. Scope: what "Edgework" is in this architecture

What we are building: the deterministic blade–ice contact and edge-control layer. It is the root of the causal chain: no glide, turn, jump entry, spin entry, edge call, or Skating Skills score exists without it.

In scope (this package):

Blade contact state (per foot)
Longitudinal friction and drag
Lateral edge force: hold vs. skid
Edge-induced curvature (the physical reason a skater on an edge travels a lobe)
Edge classification with hysteresis (FO/FI/BO/BI/flat)
Edge change events and edge lobe records (the telemetry unit that later powers edge calls and "your edge flattened 180 ms before takeoff")
Weight transfer between feet
Braking / toe-pick regimes as detection only (behaviors are later tasks)
Fixed-step integration of the body on ice
Tests, telemetry, debug draw, task graph, Codex spec

Out of scope (hooks exposed): balance recovery torque (consumes RequiredLeanRad), turns as gameplay maneuvers (consume edge lobes + steering), jumps, spins, animation.

Design rule inherited from the brief: edge state is computed from contact physics, never read from an animation state.

4. Physics model
4.1 Frames and conventions
Ice plane is z = 0 for the vertical slice (ASSUMPTION; rink surface as height field is a later task).
Per blade: Tangent t (unit, in-plane, toe-ward), Normal n = Up × t (unit, in-plane, to the skater's left when standing on that blade facing toe-ward), Up = (0,0,1).
Edge angle θ: blade tilt from vertical, positive toward n.
Edge naming (body-relative, computed, never authored):
Left foot: θ > 0 (tilt left) → Outside; θ < 0 → Inside.
Right foot: θ > 0 (tilt left) → Inside; θ < 0 → Outside.
|θ| < FlatEdgeThreshold → Flat (with hysteresis, §5).
Direction: v · t > 0 → Forward, else Backward (with hysteresis; v ≈ 0 holds previous).
4.2 Weight distribution

Total normal force must equal m·g minus vertical acceleration effects (ignored in slice; ASSUMPTION, revisited in knee-compression/jump packages):

N_left  = m g (1 - w)     N_right = m g w        w = WeightSplit, forced to 0/1 if a foot is lifted
4.3 Longitudinal friction and drag
F_long,i = -μ_long(θ_i) · N_i · sign(v_t,i) · t_i
μ_long(θ)  = MuGlide + MuEdgeGain · sin|θ|
F_drag     = -k · |v| · v

Marked ASSUMPTION: the linear-in-sin(θ) edge friction increase is a gameplay approximation, not a tribological model. It gives the correct feel (deep edges cost speed) and is tunable.

4.4 Edge-induced curvature — the core equation of edgework

A blade rocker is an arc of radius ρ in the blade plane. Tilt that plane by θ and intersect with the ice plane: the projected arc is locally an ellipse with semi-axes ρ (along t) and ρ·sin θ (along n). Its radius of curvature at the contact apex is

R_geo(θ) = ρ / sin|θ|

The blade tangent therefore rotates about Up at

ψ̇_blade = sign(θ) · v_t / R_geo = sign(θ) · v_t · sin|θ| / ρ

This is why an edge is a curve. It is kinematic, stable, and needs no force integration to turn — this is the key decision (ADR-EDGE-01). It matches how skaters describe it: lean more → tighter lobe; same lean, more speed → same radius, but more force required (which is what §4.5 checks).

Clamp: for |θ| < FlatEdgeThreshold, ψ̇_blade = 0 (a flat glides straight, apart from steering).

4.5 Lateral hold vs. skid (the "does the edge bite" test)

Required lateral (centripetal) force to actually follow R_geo:

a_req = v_t² / R_geo = v_t² · sin|θ| / ρ
F_req = (N_i / g) · a_req            ← mass share carried by this blade
F_cap = LateralHold(θ) · N_i
LateralHold(θ) = lerp(LateralHoldFlat, LateralHoldMax, saturate(|θ| / DeepEdgeThreshold))

Implementation as an impulse constraint (not a spring):

v_n      = blade velocity · n                  (lateral slip velocity)
J_needed = -(N_i/g) · v_n                      (impulse to zero the slip this tick)
J_max    = F_cap · dt
J        = clamp(J_needed, -J_max, J_max)

If |J_needed| ≤ J_max → hold (lateral slip goes to zero, regime Shallow/Deep/Carve by θ and demand ratio).
Else → Skid: slip persists, and additional lateral friction MuSkid · N_i opposes the residual slip.

LateralDemandRatio = F_req / F_cap is exported; it is exactly the signal that later becomes GOE "edge quality" and coaching ("edge was at 92% of hold capacity — you were about to skid").

4.6 Required lean (interface to balance)

For circular motion on a blade the body's resultant must pass through the contact point:

tan(φ_req) = v_t² / (g · R_geo) = v_t² · sin|θ| / (g · ρ)

Exported as RequiredLean. Edgework does not enforce balance — it reports what balance is needed. The balance module computes E_b = φ_actual − φ_req and applies recovery. Decoupling θ (blade) from φ (body) is deliberate: real skaters use ankle/knee to run a deeper edge than their body lean, and the gap is a skill signal.

4.7 Braking and toe-pick (detection only here)
misalign = angle(v_blade, ±t)  → if > BrakeAngle: Regime = Brake, lateral mu = MuBrake
Pitch > ToePickPitch           → Regime = ToePick (jump package consumes this)
4.8 Body yaw

Body yaw tracks the pressure-weighted blade tangent direction with a first-order lag YawFollowRate (tunable). Upper-body counter-rotation is a later package (spins/turns); the hook is that yaw is a separate state from blade tangent.

4.9 Integration order (per fixed tick)
1. Decode input → target θ_i, steer_i, w, lean
2. Rate-limit θ_i toward target (EdgeAngleRate)
3. Distribute N_i
4. For each contacting blade:
   a. Recompute n_i = Up × t_i
   b. blade velocity v_b = V + YawRate × r_i  (r_i = blade offset from COM in plane)
   c. Decompose v_t, v_n
   d. Apply steering to t_i (rate-limited), then edge-induced rotation ψ̇_blade · dt
   e. Lateral impulse J (hold or skid)
   f. Longitudinal friction impulse
   g. Regime + demand ratio
5. Sum impulses → V += ΣJ / m ; V += F_drag/m · dt  (semi-implicit Euler)
6. Position += V · dt
7. Yaw follows weighted tangent; RequiredLean computed from dominant blade
8. Edge classifier (§5) → events
9. Telemetry write

Fixed dt = 1/120 s (ASSUMPTION, ADR-EDGE-02). All scalar math in float (FVector3f), no double, no FMath:: functions with platform-dependent implementations in the hot path (avoid FMath::Sin on compilers that may use FMA differently across platforms — see ADR-EDGE-02 for the quantization fallback).

5. Edge classifier and lobe records
5.1 Hysteresis

Edge classification uses two thresholds to avoid event spam:

enter Inside/Outside:  |θ| > FlatEdgeThreshold · 1.25
return to Flat:        |θ| < FlatEdgeThreshold · 0.75
minimum dwell:         DwellTicks (default 6 ticks = 50 ms) before an edge change is committed

Direction hysteresis: |v_t| < 0.15 m/s holds previous direction.

// UE5 C++ IMPLEMENTATION (compiles against Core; verify includes per engine version)
#pragma once
#include "CoreMinimal.h"
#include "KoldBladeTypes.h"

struct FKoldEdgeworkTelemetryTick;

class KOLDSIM_API FKoldBladeIceSolver
{
public:
    // Pure function of inputs. Thread-safe as long as State/Telemetry are not shared.
    static void Step(FKoldSkaterEdgeworkState& State,
                     const FKoldSkatingInput& Input,
                     const FKoldBladeTuning& Tuning,
                     float Dt,
                     FKoldEdgeworkTelemetryTick* OutTelemetry /* may be null */);

    static FORCEINLINE float GeometricTurnRadius(float EdgeAngle, float RockerRadius)
    {
        const float S = FMath::Abs(FMath::Sin(EdgeAngle));
        return S > 1e-4f ? RockerRadius / S : 1e6f;
    }

    static FORCEINLINE float LateralHold(float EdgeAngle, const FKoldBladeTuning& T)
    {
        const float A = FMath::Clamp(FMath::Abs(EdgeAngle) / T.DeepEdgeThreshold, 0.f, 1.f);
        return FMath::Lerp(T.LateralHoldFlat, T.LateralHoldMax, A);
    }

    static FORCEINLINE float DecodeInput(int16 Q, float Scale)
    {
        return (static_cast<float>(Q) * (1.0f / 32767.0f)) * Scale;
    }
};
// KoldSim/Private/KoldBladeIceSolver.cpp
// UE5 C++ IMPLEMENTATION
#include "KoldBladeIceSolver.h"
#include "KoldEdgeworkTelemetry.h"

namespace
{
    constexpr FVector3f KoldUp(0.f, 0.f, 1.f);

    FORCEINLINE FVector3f RotateInPlane(const FVector3f& V, float Angle)
    {
        const float C = FMath::Cos(Angle), S = FMath::Sin(Angle);
        return FVector3f(V.X * C - V.Y * S, V.X * S + V.Y * C, 0.f);
    }

    FORCEINLINE float MoveToward(float Cur, float Target, float MaxDelta)
    {
        return Cur + FMath::Clamp(Target - Cur, -MaxDelta, MaxDelta);
    }

    FORCEINLINE EKoldEdge EdgeFromAngle(EKoldFoot Foot, float Theta, float FlatThresh)
    {
        if (FMath::Abs(Theta) < FlatThresh) return EKoldEdge::Flat;
        const bool bTiltLeft = Theta > 0.f;
        // Left foot: tilt left = outside. Right foot: tilt left = inside.
        return (Foot == EKoldFoot::Left) == bTiltLeft ? EKoldEdge::Outside : EKoldEdge::Inside;
    }
}

void FKoldBladeIceSolver::Step(FKoldSkaterEdgeworkState& S,
                               const FKoldSkatingInput& In,
                               const FKoldBladeTuning& T,
                               float Dt,
                               FKoldEdgeworkTelemetryTick* Tel)
{
    const float InvMass = 1.0f / T.SkaterMass;
    const float Gravity = T.Gravity;

    // 1. Decode input
    const float TargetEdge[2]  = { DecodeInput(In.EdgeLeft,  T.MaxEdgeAngle),
                                   DecodeInput(In.EdgeRight, T.MaxEdgeAngle) };
    const float TargetSteer[2] = { DecodeInput(In.SteerLeft,  0.6f),   // ASSUMPTION: max blade yaw 0.6 rad
                                   DecodeInput(In.SteerRight, 0.6f) };
    const bool  bLifted[2]     = { (In.Flags & 0x1) != 0, (In.Flags & 0x2) != 0 };

    float W = FMath::Clamp(DecodeInput(In.WeightSplit, 0.5f) + 0.5f, 0.f, 1.f);
    if (bLifted[0] && !bLifted[1]) W = 1.f;
    if (bLifted[1] && !bLifted[0]) W = 0.f;
    S.Body.WeightSplit = W;

    // 3. Normal force distribution (vertical acceleration ignored in slice: ASSUMPTION)
    const float TotalN = T.SkaterMass * Gravity;
    const float NShare[2] = { TotalN * (1.f - W), TotalN * W };

    FVector3f Impulse(0.f);
    float     WeightedTangentX = 0.f, WeightedTangentY = 0.f;
    float     DominantRequiredLean = 0.f;
    float     DominantN = -1.f;

    for (int32 i = 0; i < 2; ++i)
    {
        FKoldBladeState& B = S.Blade[i];
        const EKoldFoot Foot = static_cast<EKoldFoot>(i);

        B.bInContact  = !bLifted[i] && S.Body.Position.Z <= 1e-3f; // airborne → no contact (jump package sets Z)
        B.NormalForce = B.bInContact ? NShare[i] : 0.f;

        if (!B.bInContact)
        {
            B.Regime = EKoldBladeRegime::Airborne;
            B.LateralSlip = 0.f;
            B.LateralDemandRatio = 0.f;
            B.EdgeAngle = MoveToward(B.EdgeAngle, TargetEdge[i], T.EdgeAngleRate * Dt); // free-foot blade still tilts
            continue;
        }

        // 2. Edge angle control authority
        B.EdgeAngle = MoveToward(B.EdgeAngle, FMath::Clamp(TargetEdge[i], -T.MaxEdgeAngle, T.MaxEdgeAngle),
                                 T.EdgeAngleRate * Dt);

        // 4a/4b. Blade kinematics
        const float   Side   = (i == 0) ? +1.f : -1.f;
        const FVector3f BodyLeft = RotateInPlane(FVector3f(1.f, 0.f, 0.f), S.Body.Yaw + HALF_PI);
        const FVector3f R      = BodyLeft * (Side * 0.5f * S.Body.Stance);   // blade offset from COM
        B.ContactPoint = FVector3f(S.Body.Position.X + R.X, S.Body.Position.Y + R.Y, 0.f);
        const FVector3f Vb = S.Body.Velocity + FVector3f::CrossProduct(FVector3f(0.f, 0.f, S.Body.YawRate), R);

        // 4d. Steering (blade yaw relative to body, rate-limited) then edge-induced rotation
        const FVector3f BodyFwd = RotateInPlane(FVector3f(1.f, 0.f, 0.f), S.Body.Yaw);
        const FVector3f DesiredT = RotateInPlane(BodyFwd, TargetSteer[i]);
        const float CurrentRel = FMath::Atan2(B.Tangent.Y, B.Tangent.X) - FMath::Atan2(BodyFwd.Y, BodyFwd.X);
        const float SteerDelta = FMath::Clamp(FMath::FindDeltaAngleRadians(CurrentRel, TargetSteer[i]),
                                              -T.EdgeAngleRate * Dt, T.EdgeAngleRate * Dt);
        B.Tangent = RotateInPlane(B.Tangent, SteerDelta);

        const FVector3f N = FVector3f::CrossProduct(KoldUp, B.Tangent);
        const float Vt = FVector3f::DotProduct(Vb, B.Tangent);
        const float Vn = FVector3f::DotProduct(Vb, N);

        const float AbsTheta = FMath::Abs(B.EdgeAngle);
        const bool  bOnEdge  = AbsTheta >= T.FlatEdgeThreshold;
        if (bOnEdge)
        {
            // ψ̇ = sign(θ) · v_t · sin|θ| / ρ   (see §4.4)
            const float YawRateBlade = FMath::Sign(B.EdgeAngle) * Vt * FMath::Sin(AbsTheta) / T.RockerRadius;
            B.Tangent = RotateInPlane(B.Tangent, YawRateBlade * Dt);
        }
        B.Tangent.Normalize();
        (void)DesiredT;

        // 4e. Lateral impulse: hold or skid
        const float MassShare = B.NormalForce / Gravity;
        const float FCap      = LateralHold(B.EdgeAngle, T) * B.NormalForce;
        const float JMax      = FCap * Dt;
        const float JNeeded   = -MassShare * Vn;
        const float J         = FMath::Clamp(JNeeded, -JMax, JMax);
        const bool  bSkid     = FMath::Abs(JNeeded) > JMax;

        const float FReq = bOnEdge ? MassShare * (Vt * Vt * FMath::Sin(AbsTheta) / T.RockerRadius) : 0.f;
        B.LateralDemandRatio = FCap > 1e-3f ? FReq / FCap : 0.f;

        FVector3f BladeImpulse = N * J;
        if (bSkid)
        {
            // residual slip opposed by skid friction
            const float Residual = Vn + J / FMath::Max(MassShare, 1e-3f);
            BladeImpulse += N * (-FMath::Sign(Residual) * FMath::Min(T.MuSkid * B.NormalForce * Dt,
                                                                     FMath::Abs(Residual) * MassShare));
        }
        B.LateralSlip = bSkid ? Vn + J / FMath::Max(MassShare, 1e-3f) : 0.f;

        // 4f. Longitudinal friction
        const float Mu = T.MuGlide + T.MuEdgeGain * FMath::Sin(AbsTheta);
        const float JLongMax = Mu * B.NormalForce * Dt;
        const float JLong = -FMath::Sign(Vt) * FMath::Min(JLongMax, FMath::Abs(Vt) * MassShare);
        BladeImpulse += B.Tangent * JLong;

        // Brake detection: velocity strongly misaligned with tangent
        const float Speed = Vb.Size();
        const float Misalign = Speed > 0.2f ? FMath::Acos(FMath::Clamp(FMath::Abs(Vt) / Speed, 0.f, 1.f)) : 0.f;

        // 4g. Regime
        if (B.Pitch > T.ToePickPitch)           B.Regime = EKoldBladeRegime::ToePick;
        else if (Misalign > T.BrakeAngle)       B.Regime = EKoldBladeRegime::Brake;
        else if (bSkid)                         B.Regime = EKoldBladeRegime::Skid;
        else if (!bOnEdge)                      B.Regime = EKoldBladeRegime::Glide;
        else if (AbsTheta < T.DeepEdgeThreshold)B.Regime = EKoldBladeRegime::ShallowEdge;
        else if (B.LateralDemandRatio > T.CarveDemandFraction) B.Regime = EKoldBladeRegime::Carve;
        else                                    B.Regime = EKoldBladeRegime::DeepEdge;

        if (B.Regime == EKoldBladeRegime::Brake)
        {
            BladeImpulse += N * (-FMath::Sign(Vn) * FMath::Min(T.MuBrake * B.NormalForce * Dt, FMath::Abs(Vn) * MassShare));
        }

        B.Edge      = EdgeFromAngle(Foot, B.EdgeAngle, T.FlatEdgeThreshold);
        B.Direction = FMath::Abs(Vt) < 0.15f ? B.Direction
                    : (Vt > 0.f ? EKoldSkateDirection::Forward : EKoldSkateDirection::Backward);

        Impulse += BladeImpulse;
        WeightedTangentX += B.Tangent.X * B.NormalForce;
        WeightedTangentY += B.Tangent.Y * B.NormalForce;

        if (B.NormalForce > DominantN)
        {
            DominantN = B.NormalForce;
            const float ARequired = bOnEdge ? (Vt * Vt * FMath::Sin(AbsTheta) / T.RockerRadius) : 0.f;
            DominantRequiredLean = FMath::Atan(ARequired / Gravity) * FMath::Sign(B.EdgeAngle);
        }
    }

    // 5. Integrate velocity (semi-implicit Euler)
    S.Body.Velocity += Impulse * InvMass;
    const float Speed = S.Body.Velocity.Size();
    if (Speed > 1e-4f)
    {
        S.Body.Velocity -= S.Body.Velocity * (T.AirDragCoeff * Speed * InvMass * Dt);
    }
    S.Body.Velocity.Z = 0.f; // slice: no vertical motion in edgework; jump package owns Z

    // 6. Position
    S.Body.Position += S.Body.Velocity * Dt;

    // 7. Yaw follows weighted tangent (first-order lag). ASSUMPTION: 8 rad/s follow rate; tunable later.
    if (DominantN >= 0.f)
    {
        const float TargetYaw = FMath::Atan2(WeightedTangentY, WeightedTangentX);
        const float DeltaYaw  = FMath::FindDeltaAngleRadians(S.Body.Yaw, TargetYaw);
        S.Body.YawRate = FMath::Clamp(DeltaYaw * 8.0f, -6.f, 6.f);
        S.Body.Yaw    += S.Body.YawRate * Dt;
    }
    S.Body.RequiredLean = DominantRequiredLean;
    S.Body.Tick++;

    // 9. Telemetry
    if (Tel) { Tel->Capture(S); }
}

Engine-version notes: FVector3f, FMath::FindDeltaAngleRadians, and HALF_PI exist in UE 5.0+. Normalize() on FVector3f is available. Verify KOLDSIM_API export macro against your .Build.cs.

Two known simplifications to remove in later tasks (not hidden): (a) Vn in the skid branch uses pre-impulse slip and a first-order residual; a Gauss–Seidel two-blade lateral solve is task EDGE-006. (b) Yaw follow is a hard-coded lag; move to tuning in EDGE-004.

2. Edgework: Scope and Definition of Done

What we are building: the authoritative blade–ice–body layer: two blades on ice, edges that bite or skid, a body that must lean correctly for the arc it is carving, and a classifier that turns continuous physics into the discrete edge vocabulary (RFO, LBI, …) with timing that scoring and coaching can trust.

Why this first: every jump takeoff edge call, every "flattened before takeoff" coaching line, every skating-skills proxy, and every step-sequence validation reads this layer. If edges are faked here, nothing downstream can be honest.

Explicitly out of scope for EDGE-*: airborne flight, spins, falls/recovery animation, animation integration, audio, networking. Hooks for all of these are defined (airborne flag, Pivot/Spin regimes, event stream).

Definition of done (Edgework milestone): on the Ice Lab test level, with a non-animated debug proxy:

Stroke to speed, glide two-foot, transfer to one foot, hold shallow/moderate/deep edges on all 8 edge codes (backward edges reached via three-turn).
Over-edge for the speed → visible skid → fall inward. Over-lean at low speed → fall inward. Under-lean → thrown outward.
Debug overlay shows blade, edge side, contact, lateral force, predicted carve circle, COM, equilibrium lean.
A 30 s session replays from the input stream with identical state checksums every tick.
Telemetry export lets an analyst read: "RFO established t=3.12 s (tilt 22°); tilt fell to 3° at t=4.05 s — flat for 140 ms."
3. Physical Model

Sim core units: SI (m, s, kg, N, rad). UE centimeters appear only at the presentation boundary (ADR-EDGE-002).

3.1 Blade geometry

A figure blade is rockered longitudinally (radius ρ — typical 7–8 ft ≈ 2.1–2.4 m; ASSUMPTION default 2.2 m, tunable) and has a hollow producing two edges. Per blade we track:

contact point c (world), tangent t (unit, horizontal, toe-ward), right r = ẑ × t
tilt θ (rotation about t; θ > 0 ⇒ top of blade leans toward r)
rocker position s (m along blade, + toe) — set by sagittal balance; toe pick engages when s > s_toe
normal load N, pressure share w ∈ [0,1]

Edge side is a foot-relative classification of a world tilt: leaning toward r engages the right-hand edge of the hollow; for the right foot that is the lateral (outside) edge, for the left foot the medial (inside) edge. Direction is sign(v·t). This is why a three-turn (FO→BI) needs no special-case code: the body yaws 180° while the world lean is preserved, so the foot-relative side flips and the direction flips.

3.2 Steering from rocker geometry (derivation)

Tilt the rocker circle (radius ρ, in the blade plane) by θ about t. Parametrize the edge near contact: in-plane point (ρ sin τ, ρ(1−cos τ)); the in-plane vertical maps to world lateral y = ρ(1−cos τ) sin θ. Near τ=0: x ≈ ρτ, y ≈ sin θ · x²/(2ρ). Curvature of y = a x² is 2a, so the track radius is

R = ρ / sin θ

and the blade tangent rotates at  ψ̇ = v∥ · sin θ / ρ  (toward r), where v∥ = v·t is signed: skating backward rotates the tangent the other way while the path still curves toward the lean side. Sanity: θ=10° → R≈12.7 m; θ=30° → 4.4 m; θ=45° → 3.1 m. Plausible skating arcs.

3.3 Non-holonomic constraint with bite saturation (the "edge")

An edge on ice is a velocity constraint: lateral slip v·r → 0, enforced by a reaction force limited by the edge's holding capacity. Per fixed step, per loaded blade:

required impulse J_req = −m (v·r)
bite capacity F_bite = N (c₀ + c₁ sin|θ|) · sharpness · iceHardness (c₀ = flat-blade lateral μ; ASSUMPTION c₀=0.08, c₁=3.5)
if |J_req| ≤ F_bite Δt → apply J_req (slip zeroed; regime Glide/Edge/Carve)
else apply sign(J_req)·F_bite Δt; residual slip remains → Skid regime, extra longitudinal μ (ice shaving), SkidBegin event

Steady state on an arc: F_lat = m v²/R = m v² sin θ/ρ. Skid onset: v² sin θ/ρ > g(c₀ + c₁ sin θ) ⇒ for deep edges v > √(gρc₁) ≈ 8.7 m/s with defaults — i.e., very fast deep edges chatter, otherwise hold. This is the number designers will tune first.

3.4 Balance: inverted pendulum steered by angulation

Lateral lean φ (COM line vs vertical, + toward r), COM height L. In the frame co-rotating with the arc:

φ̈ = ( g sin φ − a_c cos φ ) / L + a_int/L,  a_c = realized lateral acceleration (from §3.3 impulses), a_int = bounded internal authority (arms, free leg, two-foot COP shift)

Equilibrium: tan φ_eq = a_c / g = v²/(gR). Balance error E_b = φ − φ_eq (the "angular error" — the COM should not be over the blade on an arc).

The human balance mechanism is primarily steering the base under the COM — here, angulating the blade relative to the body (ankle/knee/hip), which changes R and therefore a_c. Controller:

a_cmd = g tan φ_d + K_p (φ − φ_d) + K_d φ̇ [m/s²]
κ_cmd = a_cmd / v² (guard v² ≥ v_min²), clamp |κ| ≤ sin θ_max/ρ
θ_cmd = asin(κ_cmd ρ), clamp |θ_cmd − φ| ≤ α_max (angulation limit), clamp |θ| ≤ θ_max
θ ← first-order lag(θ_cmd, τ_latency)

Linearized about φ_d: δφ̈ ≈ ((g − K_p) δφ − K_d δφ̇)/L → stable iff K_p > g; ω_n = √((K_p−g)/L), ζ = K_d / (2√(L(K_p−g))). Defaults K_p = 39 m/s²/rad, K_d = 8 → ω_n ≈ 5.5 rad/s, ζ ≈ 0.76.

Emergent skill expression (not scripted):

No speed, no edge: at 2 m/s a 20° lean needs sin θ = 1.96 → impossible → clamped → falls inward.
Angulation limit: a lean beyond what α_max can steer under → wobble → fall.
Skid → inward fall: bite saturation reduces a_c below g tan φ.
Assist tiers scale τ_latency, K_p/K_d, α_max transparently (§10 task EDGE-010) and are reported to scoring.
3.5 Sagittal balance and toe pick

Same structure fore/aft: pitch lean φ_p with equilibrium tan φ_p,eq = a∥/g. Control authority = moving the contact along the rocker: Δs = clamp(K_s E_p L, −L_heel, L_toe). s ≥ s_toe with v∥ > v_trip → ToePickCatch (trip); s ≤ −L_heel → heel-off. (Implemented in EDGE-005; the code in §7 shows the lateral channel, the sagittal channel is the mirror.)

3.6 Friction and drag
μ_long(v, θ, skid) = μ_glide(v) · (1 + k_e (1 − cos θ)) + [skid] μ_skid. μ_glide(v) baked from an authoring curve; literature range for skates ~0.003–0.007 (ASSUMPTION default 0.005; k_e = 0.6; μ_skid = 0.03).
Never reverse velocity from friction (impulse clamped to |v∥|).
Aero drag F = ½ ρ_air C_dA v² (ASSUMPTION C_dA = 0.45 m² upright).
3.7 Regimes

Unloaded, Glide (|θ|<θ_flat), Edge, Carve (|F_lat| > 0.5N), Skid, ToePick, Pivot (turn cusp), Spin (reserved) — determined every step from continuous state with hysteresis, never from animation.

3.8 Stroke (EDGE-011, algorithm)

Push blade tangent = heading rotated outward by β (data: 30–45°), on its inside edge. Leg force profile F_leg(t) along the push blade's inward normal, clamped by that blade's F_bite(θ_push, N_push). Propulsive component along heading = F sin β. Push contact advects along its own tangent (so it recedes relative to the body); stroke ends when separation > leg reach or profile ends; weight transfers to glide foot. Emergent: you cannot push off a flat blade; over-pushing a lightly loaded blade skids. This is a semi-analytic approximation (ADR-EDGE-001 consequence), not a full leg model.

3.9 Three-turn (EDGE-012, algorithm)

Pivot phase (τ_p ≈ 0.18 s, ASSUMPTION): tangent yaw driven by ω = π/τ_p toward the tilt side; lateral constraint relaxed with μ_pivot (speed loss); bite check suspended; re-engage constraint on exit. Requires an upper-body "check" input inside a window or yaw continues (over-rotation → skid). Emits TurnEvent{entryCode, exitCode, speedRetained, cuspQuality}. FO→BI emerges from §3.1.

4. Data Contracts (hot path)

/** Packed edge code: bit0 = foot, bits1-2 = direction, bits3-4 = side. 0xFF = none/unloaded. */
struct KOLDSIMCORE_API FEdgeCode
{
	static constexpr uint8 None = 0xFF;

	static constexpr uint8 Make(EFoot Foot, ESkateDirection Dir, EEdgeSide Side)
	{
		return static_cast<uint8>(static_cast<uint8>(Foot)
			| (static_cast<uint8>(Dir)  << 1)
			| (static_cast<uint8>(Side) << 3));
	}
	static constexpr EFoot           GetFoot(uint8 C) { return static_cast<EFoot>(C & 1); }
	static constexpr ESkateDirection GetDir (uint8 C) { return static_cast<ESkateDirection>((C >> 1) & 3); }
	static constexpr EEdgeSide       GetSide(uint8 C) { return static_cast<EEdgeSide>((C >> 3) & 3); }

	/** "RFO", "LBI", "RF-" (flat), "L--" (stationary). Debug/telemetry only — never in the hot path.
	 *  VERIFY: must match the repository's existing edge naming once audited (§1.1 Q1). */
	static FString ToString(uint8 C);
};
7.2 Deterministic math — KoLdDeterministicMath.h (UE5 C++ IMPLEMENTATION)
#pragma once
#include "CoreMinimal.h"

// ADR-EDGE-007: every solver goes through this namespace so the transcendental implementation can be
// swapped for a bit-exact cross-platform library without touching solver code.
// Phase-1 policy: same-platform determinism (FMath → platform libm).
namespace KoLdMath
{
	FORCEINLINE float Sqrt (float X)          { return FMath::Sqrt(X); }   // IEEE-754 correctly rounded everywhere
	FORCEINLINE float Sin  (float X)          { return FMath::Sin(X);  }   // VERIFY: libm may differ by ulps across platforms/compilers
	FORCEINLINE float Cos  (float X)          { return FMath::Cos(X);  }
	FORCEINLINE float Tan  (float X)          { return FMath::Tan(X);  }
	FORCEINLINE float Asin (float X)          { return FMath::Asin(FMath::Clamp(X, -1.0f, 1.0f)); }
	FORCEINLINE float Atan2(float Y, float X) { return FMath::Atan2(Y, X); }
	FORCEINLINE float Sign (float X)          { return X > 0.f ? 1.f : (X < 0.f ? -1.f : 0.f); }

	FORCEINLINE float Dot(const FVector3f& A, const FVector3f& B) { return A.X*B.X + A.Y*B.Y + A.Z*B.Z; }
	FORCEINLINE FVector3f Cross(const FVector3f& A, const FVector3f& B)
	{
		return FVector3f(A.Y*B.Z - A.Z*B.Y, A.Z*B.X - A.X*B.Z, A.X*B.Y - A.Y*B.X);
	}

	/** Deterministic normalize. Deliberately avoids FVector::GetSafeNormal, which uses FMath::InvSqrt
	 *  (platform-specific rsqrt approximations → non-identical bits across targets). */
	FORCEINLINE FVector3f NormalizeOr(const FVector3f& V, const FVector3f& Fallback)
	{
		const float L2 = V.X*V.X + V.Y*V.Y + V.Z*V.Z;
		if (L2 <= 1e-12f) return Fallback;
		const float Inv = 1.0f / Sqrt(L2);
		return FVector3f(V.X*Inv, V.Y*Inv, V.Z*Inv);
	}
}

FString FEdgeCode::ToString(uint8 C)
{
	if (C == None) { return TEXT("---"); }
	const TCHAR F = GetFoot(C) == EFoot::Right ? TEXT('R') : TEXT('L');
	const TCHAR D = GetDir(C)  == ESkateDirection::Forward  ? TEXT('F')
	              : GetDir(C)  == ESkateDirection::Backward ? TEXT('B') : TEXT('-');
	const TCHAR Sd= GetSide(C) == EEdgeSide::Outside ? TEXT('O')
	              : GetSide(C) == EEdgeSide::Inside  ? TEXT('I') : TEXT('-');
	return FString::Printf(TEXT("%c%c%c"), F, D, Sd);
}

uint32 FSkaterSimulationState::Checksum() const
{
	// Quantize to 0.1 mm / 1e-5 rad by truncation (exact in IEEE), then CRC. Tick included so replays can locate divergence.
	int32 Q[10] = {
		int32(Position.X * 1e4f), int32(Position.Y * 1e4f), int32(Position.Z * 1e4f),
		int32(Velocity.X * 1e4f), int32(Velocity.Y * 1e4f),
		int32(Heading.X  * 1e6f), int32(Heading.Y  * 1e6f),
		int32(Lean * 1e5f), int32(LeanRate * 1e5f), int32(Tick) };
	return FCrc::MemCrc32(Q, sizeof(Q));
}

float FEdgeworkSolver::EquilibriumLean(float LateralAccel)
{
	return KoLdMath::Atan2(LateralAccel, KoLd::kGravity);                   // tan φ_eq = a_c / g
}

float FEdgeworkSolver::ComputeBiteCapacity(const FEdgeworkParams& P, float N, float Tilt)
{
	// F_bite = N (c0 + c1 sin|θ|) · sharpness · hardness — lateral holding capacity before the edge lets go (§3.3)
	return N * (P.BiteC0 + P.BiteC1 * KoLdMath::Sin(FMath::Abs(Tilt))) * P.Sharpness * P.IceHardness;
}

float FEdgeworkSolver::ComputeMuLong(const FEdgeworkParams& P, float Speed, float Tilt, bool bSkid)
{
	float Mu = P.MuGlide(Speed) * (1.0f + P.MuEdgeGain * (1.0f - KoLdMath::Cos(Tilt)));
	if (bSkid) { Mu += P.MuSkidLong; }
	return Mu;
}

EEdgeDepth FEdgeworkSolver::ClassifyDepth(const FEdgeworkParams& P, float Tilt)
{
	const float A = FMath::Abs(Tilt);
	if (A < P.FlatThresholdRad) { return EEdgeDepth::Flat; }
	if (A < P.DepthShallowRad)  { return EEdgeDepth::Shallow; }
	if (A < P.DepthDeepRad)     { return EEdgeDepth::Moderate; }
	return EEdgeDepth::Deep;
}

uint8 FEdgeworkSolver::ClassifyEdge(const FEdgeworkParams& P, EFoot Foot, float Tilt, float LongSpeed, uint8 Prev)
{
	// --- side, with hysteresis around the flat threshold (ADR-EDGE-004) ---
	const bool  bPrevFlat = (Prev == FEdgeCode::None) || (FEdgeCode::GetSide(Prev) == EEdgeSide::Flat);
	const float Enter = P.FlatThresholdRad + P.FlatHysteresisRad;
	const float Leave = P.FlatThresholdRad - P.FlatHysteresisRad;
	const float A = FMath::Abs(Tilt);
	EEdgeSide Side = EEdgeSide::Flat;
	if (bPrevFlat ? (A > Enter) : (A > Leave))
	{
		// +Tilt = top leans toward Right (= Up × Tangent). For the RIGHT foot that is the lateral (outside) side;
		// for the LEFT foot it is the medial (inside) side. Direction flips (three-turn) fall out of this rule.
		const bool bLateral = (Foot == EFoot::Right) ? (Tilt > 0.f) : (Tilt < 0.f);
		Side = bLateral ? EEdgeSide::Outside : EEdgeSide::Inside;
	}
	// --- direction with dead-band; hold previous direction inside the band ---
	ESkateDirection Dir;
	if      (LongSpeed >  P.DirSpeedEps) { Dir = ESkateDirection::Forward;  }
	else if (LongSpeed < -P.DirSpeedEps) { Dir = ESkateDirection::Backward; }
	else { Dir = (Prev == FEdgeCode::None) ? ESkateDirection::Stationary : FEdgeCode::GetDir(Prev); }
	return FEdgeCode::Make(Foot, Dir, Side);
}

void FEdgeworkSolver::Step(const FEdgeworkParams& P, const FSkaterProfile& S, const FSkatingInput& In,
                           FSkaterSimulationState& St, FEdgeworkStepOutput& Out)
{
	SCOPE_CYCLE_COUNTER(STAT_EdgeworkStep);
	using namespace KoLdMath;
	constexpr float dt = KoLd::kSimDt;
	constexpr float g  = KoLd::kGravity;
	const FVector3f Up(0.f, 0.f, 1.f);
	St.Tick++;

	// ---------- 1. Decode quantized input ----------
	const float LeanCmd = float(In.LeanX) * (P.MaxLeanCmdRad / 127.0f);
	const float KneeCmd = float(In.KneeY) * (1.0f / 127.0f);            // -1 deep .. +1 tall
	const float WeightR = float(In.WeightLR) * (1.0f / 255.0f);
	const float Weights[2] = { 1.0f - WeightR, WeightR };

	// ---------- 2. Vertical leg model → normal load ----------
	// Simplification (documented): a_z ≈ leg-axis acceleration; lean cosines omitted. Jump tasks own true flight.
	const float LegTarget = S.COMHeightStanding * (1.0f - P.MaxKneeCompression * 0.5f * (1.0f - KneeCmd));
	const float LegAccel  = P.KneeSpring * (LegTarget - St.LegLength) - P.KneeDamping * St.LegRate;
	St.LegRate   += LegAccel * dt;
	St.LegLength += St.LegRate * dt;
	const float NTotal = FMath::Max(0.0f, S.Mass * (g + LegAccel));
	St.bAirborne = (NTotal <= 1e-3f) ? 1 : 0;

	int32 NumLoaded = 0;
	for (int32 i = 0; i < 2; ++i)
	{
		FBladeState& B = St.Blade[i];
		B.PressureWeight = Weights[i];
		B.NormalLoad     = NTotal * Weights[i];
		B.bInContact     = (B.NormalLoad > 1e-3f) ? 1 : 0;
		NumLoaded       += B.bInContact;
	}
	St.SupportMode = uint8(NumLoaded);
	St.SupportFoot = (Weights[1] >= Weights[0]) ? uint8(EFoot::Right) : uint8(EFoot::Left);   // fixed tie rule (determinism)

	// ---------- 3. Balance controller: lean error → commanded blade tilt (§3.4) ----------
	{
		const float V2 = FMath::Max(St.Velocity.X*St.Velocity.X + St.Velocity.Y*St.Velocity.Y,
		                            P.MinSpeedForCurv * P.MinSpeedForCurv);
		// Lateral acceleration (toward Right) required to hold LeanCmd, plus PD correction on lean error. [m/s^2]
		const float ACmd = g * Tan(LeanCmd) + P.BalanceKp * (St.Lean - LeanCmd) + P.BalanceKd * St.LeanRate;
		// κ = a / v² ; carve geometry sin θ = κ ρ  (R = ρ / sin θ, §3.2)
		const float KappaMax = Sin(P.MaxTiltRad) / P.RockerRadius;
		const float Kappa    = FMath::Clamp(ACmd / V2, -KappaMax, KappaMax);
		float TiltTarget     = Asin(Kappa * P.RockerRadius);
		// Angulation limit: blade cannot tilt arbitrarily relative to the body lean (ankle/knee/hip)
		TiltTarget = FMath::Clamp(TiltTarget, St.Lean - P.AngulationLimitRad, St.Lean + P.AngulationLimitRad);
		TiltTarget = FMath::Clamp(TiltTarget, -P.MaxTiltRad, P.MaxTiltRad);
		// Neuromuscular latency: first-order lag. Assist tiers shrink ControlLatencySec (EDGE-010).
		const float LagAlpha = (P.ControlLatencySec > 1e-4f) ? FMath::Min(1.0f, dt / P.ControlLatencySec) : 1.0f;
		St.TiltCmd += (TiltTarget - St.TiltCmd) * LagAlpha;
	}

	// ---------- 4. Steering: a rockered blade on an edge follows R = ρ / sin θ (§3.2) ----------
	for (int32 i = 0; i < 2; ++i)
	{
		FBladeState& B = St.Blade[i];
		if (!B.bInContact) { continue; }
		B.Tilt = St.TiltCmd;                                   // both blades tilt with the body in this slice
		const FVector3f BRight = Cross(Up, B.Tangent);
		const float BLong = Dot(St.Velocity, B.Tangent);       // signed: backward travel rotates the tangent the other way
		const float dPsi  = BLong * Sin(B.Tilt) / P.RockerRadius * dt;
		const float c = Cos(dPsi), s = Sin(dPsi);
		B.Tangent = NormalizeOr(B.Tangent * c + BRight * s, B.Tangent);
	}
	St.Heading = St.Blade[St.SupportFoot].Tangent;
	const FVector3f Right = Cross(Up, St.Heading);

	// ---------- 5. Non-holonomic blade constraint with bite saturation (§3.3) ----------
	float LatImpulseSum = 0.0f;                                // toward Right
	const int32 Order[2] = { int32(St.SupportFoot), 1 - int32(St.SupportFoot) };   // heavier blade first, fixed rule
	for (int32 k = 0; k < 2; ++k)
	{
		FBladeState& B = St.Blade[Order[k]];
		if (!B.bInContact)
		{
			B.Regime = uint8(EBladeRegime::Unloaded); B.LatForce = 0.f; B.LongForce = 0.f; B.LatSlip = 0.f; B.BiteCapacity = 0.f;
			continue;
		}
		const FVector3f BRight = Cross(Up, B.Tangent);
		const float VLat = Dot(St.Velocity, BRight);
		const float JReq = -S.Mass * VLat;                     // impulse that would zero lateral slip
		B.BiteCapacity   = ComputeBiteCapacity(P, B.NormalLoad, B.Tilt);
		const float JMax = B.BiteCapacity * dt;
		const bool bWasSkid = (B.Regime == uint8(EBladeRegime::Skid));

		float J;
		if (FMath::Abs(JReq) <= JMax) { J = JReq;               B.LatSlip = 0.0f; }
		else                          { J = Sign(JReq) * JMax;  B.LatSlip = VLat + J / S.Mass; }

		St.Velocity   += BRight * (J / S.Mass);
		B.LatForce     = J / dt;
		LatImpulseSum += J * Dot(BRight, Right);

		const bool bSkid = (B.LatSlip != 0.0f);
		if (bSkid && !bWasSkid) { Out.Push(FEdgeEvent{ St.Tick, 0, uint8(EEdgeEventType::SkidBegin), B.EdgeCode, B.EdgeCode, B.EdgeDwell, VLat }); }
		if (!bSkid && bWasSkid) { Out.Push(FEdgeEvent{ St.Tick, 0, uint8(EEdgeEventType::SkidEnd),   B.EdgeCode, B.EdgeCode, B.EdgeDwell, 0.f  }); }

		if      (bSkid)                                   { B.Regime = uint8(EBladeRegime::Skid);  }
		else if (FMath::Abs(B.Tilt) < P.FlatThresholdRad) { B.Regime = uint8(EBladeRegime::Glide); }
		else { B.Regime = (FMath::Abs(B.LatForce) > P.CarveLoadFraction * B.NormalLoad) ? uint8(EBladeRegime::Carve) : uint8(EBladeRegime::Edge); }
		// ToePick / Pivot regimes are assigned by EDGE-005 / EDGE-012 before this block.
	}
	St.LateralAccelActual = LatImpulseSum / (S.Mass * dt);

	// ---------- 6. Longitudinal friction + aero drag (§3.6) ----------
	for (int32 i = 0; i < 2; ++i)
	{
		FBladeState& B = St.Blade[i];
		if (!B.bInContact) { continue; }
		const float BLong = Dot(St.Velocity, B.Tangent);
		B.LongSpeed = BLong;
		const float Mu = ComputeMuLong(P, FMath::Abs(BLong), B.Tilt, B.Regime == uint8(EBladeRegime::Skid));
		float DV = Mu * B.NormalLoad / S.Mass * dt;
		DV = FMath::Min(DV, FMath::Abs(BLong));               // friction never reverses motion
		St.Velocity -= B.Tangent * (Sign(BLong) * DV);
		B.LongForce  = -Sign(BLong) * Mu * B.NormalLoad;
	}
	{
		const float Speed = Sqrt(St.Velocity.X*St.Velocity.X + St.Velocity.Y*St.Velocity.Y);
		if (Speed > 1e-4f)
		{
			const float Fd = 0.5f * P.AirDensity * P.CdA * Speed * Speed;
			const float DV = FMath::Min(Fd / S.Mass * dt, Speed);
			St.Velocity -= FVector3f(St.Velocity.X, St.Velocity.Y, 0.f) * (DV / Speed);
		}
	}

	// ---------- 7. Integrate COM (semi-implicit Euler; velocity already updated) ----------
	St.Velocity.Z = 0.0f;                                     // contact slice; JUMP-* owns vertical flight
	St.Position  += St.Velocity * dt;

	// ---------- 8. Lateral inverted pendulum (§3.4) ----------
	{
		const float L = FMath::Max(St.LegLength, 0.3f);
		const float LeanEq = EquilibriumLean(St.LateralAccelActual);
		St.BalanceError = St.Lean - LeanEq;
		// Bounded internal authority (arms / free leg) + center-of-pressure shift when two-footed
		float InternalAccel = FMath::Clamp(-P.InternalAccelGain * St.BalanceError, -P.InternalAccelMax, P.InternalAccelMax);
		if (St.SupportMode == 2)
		{
			const float CopMax = g * S.StanceHalfWidth / L;   // shifting COP by ±stance half-width
			InternalAccel += FMath::Clamp(-P.TwoFootCopGain * St.BalanceError, -CopMax, CopMax);
		}
		const float LeanAccel = (g * Sin(St.Lean) - (St.LateralAccelActual + InternalAccel) * Cos(St.Lean)) / L;
		St.LeanRate += LeanAccel * dt;
		St.Lean     += St.LeanRate * dt;
		St.Lean      = FMath::Clamp(St.Lean, -1.55f, 1.55f);
		St.Position.Z = L * Cos(St.Lean);                     // ice at z = 0 (ASSUMPTION: flat rink in the slice)

		// Blade contact points follow the pendulum base (ground projection of the COM along the lean line)
		const FVector3f BaseXY = FVector3f(St.Position.X, St.Position.Y, 0.f) - Right * (L * Sin(St.Lean));
		for (int32 i = 0; i < 2; ++i)
		{
			const float Side = (i == int32(EFoot::Right)) ? 1.0f : -1.0f;
			const float Offset = (St.SupportMode == 2) ? S.StanceHalfWidth : 0.0f;
			St.Blade[i].Contact = BaseXY + Right * (Side * Offset);
		}
	}

	// ---------- 9. Edge classification, dwell, events (§8) ----------
	for (int32 i = 0; i < 2; ++i)
	{
		FBladeState& B = St.Blade[i];
		const uint8 Prev = B.EdgeCode;
		if (!B.bInContact)
		{
			if (Prev != FEdgeCode::None) { Out.Push(FEdgeEvent{ St.Tick, 0, uint8(EEdgeEventType::EdgeLost), Prev, FEdgeCode::None, B.EdgeDwell, B.Tilt }); }
			B.EdgeCode = FEdgeCode::None; B.EdgeDwell = 0.f; B.Depth = uint8(EEdgeDepth::Flat);
			continue;
		}
		const uint8 New = ClassifyEdge(P, EFoot(i), B.Tilt, B.LongSpeed, Prev);
		if (New != Prev)
		{
			Out.Push(FEdgeEvent{ St.Tick, 0, uint8(EEdgeEventType::EdgeChanged), Prev, New, B.EdgeDwell, B.Tilt });
			B.EdgeCode = New; B.EdgeDwell = 0.0f;
		}
		else
		{
			const float PrevDwell = B.EdgeDwell;
			B.EdgeDwell += dt;
			if (PrevDwell < P.MinEdgeDwellSec && B.EdgeDwell >= P.MinEdgeDwellSec)
			{
				Out.Push(FEdgeEvent{ St.Tick, 0, uint8(EEdgeEventType::EdgeEstablished), New, New, B.EdgeDwell, B.Tilt });
			}
		}
		B.Depth = uint8(ClassifyDepth(P, B.Tilt));
	}

	// ---------- 10. Fall detection (state machine layer consumes FallTriggered) ----------
	St.FallReason = uint8(EFallReason::None);
	if (FMath::Abs(St.Lean) > P.FallLeanRad) { St.FallReason = uint8(EFallReason::LeanExceeded); }
	if (FMath::Abs(St.BalanceError) > P.FallErrorRad)
	{
		St.BalanceErrorTime += dt;
		if (St.BalanceErrorTime > P.FallErrorTimeSec) { St.FallReason = uint8(EFallReason::BalanceErrorTimeout); }
	}
	else { St.BalanceErrorTime = 0.0f; }
	if (St.FallReason != uint8(EFallReason::None))
	{
		Out.Push(FEdgeEvent{ St.Tick, 0, uint8(EEdgeEventType::FallTriggered), St.Blade[St.SupportFoot].EdgeCode, St.FallReason, St.BalanceErrorTime, St.Lean });
	}
}

Documented approximations in this step (each is a tracked tuning/upgrade item, not hidden): (a) the lateral constraint is applied to the COM velocity, treating lean as an internal DoF rather than constraining the base point and letting the COM swing; (b) both blades share one tilt (angulation per blade arrives with EDGE-011 stroke); (c) flat ice at z=0 (ice-height query hook in EDGE-005).

7.6 Fixed-step subsystem — USkatingSimulationSubsystem (ILLUSTRATIVE — structure is exact, project glue omitted)
UCLASS()
class KOLDSKATING_API USkatingSimulationSubsystem : public UWorldSubsystem
{
	GENERATED_BODY()
public:
	virtual void Initialize(FSubsystemCollectionBase& Collection) override
	{
		Super::Initialize(Collection);
		// Step BEFORE any actor/animation ticks so presentation reads authoritative state (ADR-EDGE-008).
		// VERSION-SENSITIVE: verify FWorldDelegates::OnWorldPreActorTick signature (UWorld*, ELevelTick, float) in your engine.
		PreTickHandle = FWorldDelegates::OnWorldPreActorTick.AddUObject(this, &USkatingSimulationSubsystem::OnPreActorTick);
	}
	virtual void Deinitialize() override { FWorldDelegates::OnWorldPreActorTick.Remove(PreTickHandle); Super::Deinitialize(); }

	int32 RegisterSkater(const FSkaterProfile& Profile, const FSkaterSimulationState& Initial);   // returns compact handle
	void  PushInput(int32 Handle, const FSkatingInput& Input) { Inputs[Handle] = Input; }          // latched per tick
	const FSkaterSimulationState& GetState(int32 Handle) const { return Cur[Handle]; }
	float GetInterpAlpha() const { return InterpAlpha; }
	void  GetInterpolated(int32 Handle, FVector& OutPosUU, FVector& OutHeading) const;              // Prev/Cur lerp, ×100 to cm

	FSimpleMulticastDelegate OnFixedStepComplete;    // telemetry/replay hook (game thread)

private:
	void OnPreActorTick(UWorld* World, ELevelTick, float DeltaSeconds)
	{
		if (World != GetWorld()) { return; }
		Accumulator += FMath::Min(double(DeltaSeconds), 0.25);        // clamp hitch
		int32 Steps = 0;
		while (Accumulator >= KoLd::kSimDt && Steps < MaxStepsPerFrame) { FixedStep(); Accumulator -= KoLd::kSimDt; ++Steps; }
		if (Steps == MaxStepsPerFrame && Accumulator >= KoLd::kSimDt)   // spiral-of-death guard: drop TIME, never alter step semantics
		{
			UE_LOG(LogKoLdSkating, Warning, TEXT("Sim fell behind; dropping %.3f s"), Accumulator); Accumulator = 0.0;
		}
		InterpAlpha = float(Accumulator / KoLd::kSimDt);
	}
	void FixedStep()
	{
		TRACE_CPUPROFILER_EVENT_SCOPE(KoLd_FixedStep);
		for (int32 i = 0; i < Cur.Num(); ++i)
		{
			Prev[i] = Cur[i];
			StepOutputs[i].Reset();
			FEdgeworkSolver::Step(Params, Profiles[i], Inputs[i], Cur[i], StepOutputs[i]);
			for (int32 e = 0; e < StepOutputs[i].NumEvents; ++e) { StepOutputs[i].Events[e].SkaterId = uint8(i); }
			// Replay stream: (Tick, Inputs[i]) appended by KoLdTelemetry listener on OnFixedStepComplete (EDGE-016)
		}
		++SimTick;
		OnFixedStepComplete.Broadcast();
	}

	FEdgeworkParams Params;                       // baked once from UEdgeworkTuningAsset (EDGE-003)
	TArray<FSkaterProfile>          Profiles;     // all arrays preallocated to kMaxSkaters — no per-frame allocation
	TArray<FSkatingInput>           Inputs;
	TArray<FSkaterSimulationState>  Cur, Prev;
	TArray<FEdgeworkStepOutput>     StepOutputs;
	double Accumulator = 0.0; float InterpAlpha = 0.f; uint64 SimTick = 0;
	int32 MaxStepsPerFrame = 8;
	FDelegateHandle PreTickHandle;
};
7.7 Tuning asset with validated bake (ILLUSTRATIVE — property list abbreviated)
UCLASS(BlueprintType)
class KOLDSKATING_API UEdgeworkTuningAsset : public UPrimaryDataAsset
{
	GENERATED_BODY()
public:
	UPROPERTY(EditAnywhere, Category="Blade", meta=(ClampMin="1.0", ClampMax="4.0"))  float RockerRadiusMeters = 2.2f;
	UPROPERTY(EditAnywhere, Category="Ice")   TObjectPtr<UCurveFloat> MuGlideVsSpeed;          // authoring curve → baked LUT
	UPROPERTY(EditAnywhere, Category="Bite",  meta=(ClampMin="0.0"))  float BiteC0 = 0.08f;
	UPROPERTY(EditAnywhere, Category="Bite",  meta=(ClampMin="0.0"))  float BiteC1 = 3.5f;
	UPROPERTY(EditAnywhere, Category="Edge",  meta=(ClampMin="0.0", ClampMax="20.0")) float FlatThresholdDeg = 4.f;
	UPROPERTY(EditAnywhere, Category="Edge",  meta=(ClampMin="0.0", ClampMax="10.0")) float FlatHysteresisDeg = 1.5f;
	UPROPERTY(EditAnywhere, Category="Balance") float BalanceKp = 39.f;
	UPROPERTY(EditAnywhere, Category="Balance") float BalanceKd = 8.f;
	// ... remaining fields mirror FEdgeworkParams, authored in degrees where human-facing

	/** Authoring → Validated → Runtime. Returns false with human-readable reasons on impossible ranges. */
	bool Bake(FEdgeworkParams& Out, TArray<FString>& OutErrors) const
	{
		Out = FEdgeworkParams();
		Out.RockerRadius = RockerRadiusMeters;
		Out.BiteC0 = BiteC0; Out.BiteC1 = BiteC1;
		Out.FlatThresholdRad  = FMath::DegreesToRadians(FlatThresholdDeg);
		Out.FlatHysteresisRad = FMath::DegreesToRadians(FlatHysteresisDeg);
		Out.BalanceKp = BalanceKp; Out.BalanceKd = BalanceKd;
		if (MuGlideVsSpeed)
		{
			for (int32 i = 0; i < FEdgeworkParams::kMuLutSize; ++i)
			{
				const float V = Out.MuLutMaxSpeed * float(i) / float(FEdgeworkParams::kMuLutSize - 1);
				Out.MuGlideLut[i] = FMath::Max(0.f, MuGlideVsSpeed->GetFloatValue(V));
			}
		}
		// --- validation rules (data test EDGE-003) ---
		if (Out.FlatHysteresisRad >= Out.FlatThresholdRad) { OutErrors.Add(TEXT("FlatHysteresis must be < FlatThreshold")); }
		if (Out.BalanceKp <= KoLd::kGravity)               { OutErrors.Add(TEXT("BalanceKp must exceed g (9.81) or the lean loop is unstable")); }
		if (Out.MinEdgeDwellSec < 2.f * KoLd::kSimDt)      { OutErrors.Add(TEXT("MinEdgeDwellSec below 2 sim ticks")); }
		if (Out.DepthShallowRad >= Out.DepthDeepRad)       { OutErrors.Add(TEXT("DepthShallow must be < DepthDeep")); }
		return OutErrors.Num() == 0;
	}
};

	static FSkaterSimulationState Gliding(float Speed, float Lean = 0.f)
	{
		FSkaterSimulationState St;
		St.Position = FVector3f(0.f, 0.f, 0.95f); St.Velocity = FVector3f(Speed, 0.f, 0.f);
		St.Heading = FVector3f(1.f, 0.f, 0.f); St.LegLength = 0.95f; St.Lean = Lean;

		for (int32 i = 0; i < Steps; ++i) { O.Reset(); FEdgeworkSolver::Step(P, S, In, St, O); }
	}

IMPLEMENT_SIMPLE_AUTOMATION_TEST(FKoLdEdgeCarveRadius, "KoLdFEEt.Edgework.Steering.CarveRadiusMatchesRockerGeometry", KOLD_TEST_FLAGS)
bool FKoLdEdgeCarveRadius::RunTest(const FString&)
{
	using namespace KoLdTestUtil;
	FEdgeworkParams P; FSkaterProfile S; ZeroDissipation(P); P.ControlLatencySec = 0.f;
	const float LeanCmd = FMath::DegreesToRadians(20.f);
	FSkaterSimulationState St = Gliding(4.0f, LeanCmd);
	const FSkatingInput In = Input(LeanCmd, P);
	Run(P, S, In, St, 240);                                                    // settle 2 s
	const FVector3f H0 = St.Heading;
	Run(P, S, In, St, 120);                                                    // measure over 1 s
	const float Turned = FMath::Abs(KoLdMath::Atan2(KoLdMath::Cross(H0, St.Heading).Z, KoLdMath::Dot(H0, St.Heading)));
	const float V = KoLdMath::Sqrt(St.Velocity.X*St.Velocity.X + St.Velocity.Y*St.Velocity.Y);
	const float RMeasured = V / Turned;
	const float RExpected = P.RockerRadius / KoLdMath::Sin(FMath::Abs(St.Blade[1].Tilt));
	TestEqual(TEXT("no fall"), int32(St.FallReason), int32(EFallReason::None));
	TestTrue(TEXT("lean tracks command within 2 deg"), FMath::Abs(St.Lean - LeanCmd) < FMath::DegreesToRadians(2.f));
	TestTrue(TEXT("carve radius within 5% of rho/sin(theta)"), FMath::Abs(RMeasured - RExpected) / RExpected < 0.05f);
	TestTrue(TEXT("speed conserved without dissipation (<1%)"), FMath::Abs(V - 4.0f) < 0.04f);
	return true;
}

8. Edge Classification, Events, and the History API for Validators
Classification (ClassifyEdge): side with enter/leave hysteresis; direction with dead-band and hold; depth thresholds. Runs per blade per tick; zero allocation.
Events: EdgeChanged (with previous dwell — a change after <MinDwell is a flicker, validators ignore it), EdgeEstablished (dwell crosses MinDwell — this is the timestamp scoring uses for "on edge"), EdgeLost, SkidBegin/End, ToePickCatch, FallTriggered.
History (FEdgeHistory, EDGE-009): per blade ring of 256 × FEdgeSample{int16 TiltQ, int16 SpeedQ, int16 LoadQ, uint8 Code, uint8 Regime}; Summarize(FromTick, ToTick) → {DominantCode, FractionOnDominant, MinAbsTilt, FlatTimeSec, MeanTilt, MeanSpeed, SkidTimeSec}. This is the exact query a Lutz validator issues for [TakeoffTick − 0.18 s, TakeoffTick], and the coaching layer turns into "outside edge flattened during the final 180 ms" (§39 causal telemetry).

Scoring/GOE signals originating here (consumed later, defined now): edge depth consistency, |F_lat|/N (edge pressure), skid time, speed retained across turns, RMS balance error (wobble), assist tier.

9. Telemetry

FEdgeworkTelemetryFrame (128 B, per tick): Tick, Position, Velocity, Lean, LeanEq, BalanceError, LateralAccelActual, TiltCmd, SupportMode, SupportFoot, FallReason, per blade {EdgeCode, Depth, Regime, Tilt, NormalLoad, LatForce, BiteCapacity, LatSlip, LongSpeed, EdgeDwell}. Ring buffer 2 s hot; on FallTriggered, the last 2 s are frozen into a "fall dump" (this is the "why did the skater fall" artifact). Export: CSV/JSON via commandlet (EDGE-013). Same frames drive automated tests, the replay checksum diff, and future AI coaching.

10. Input and Assists (EDGE-010)

Mapping is a design decision, ASSUMPTION for the slice: LS-X = desired lean, LS-Y = knee, LT/RT = left/right foot weight (analog → WeightLR), face button = stroke (alternating), bumper = turn, RS = upper body (check/twist). Enhanced Input produces floats; the adapter quantizes to FSkatingInput once per render frame; the sim latches per tick.

Assist tiers (FULL SIMULATION / ASSISTED / COMPETITIVE / ACCESSIBLE) are parameter overlays on FEdgeworkParams: ControlLatencySec (0.12 → 0.04 → 0), BalanceKp/Kd (+0/+25%/+60%), AngulationLimitRad (20°/25°/30°), InternalAccelMax. The active tier is written to every FSkatingInput, so it appears in replay, telemetry, and the scoring record. VERIFY tier semantics against the repository's assist-tier data before implementing.
