# Edgework anime key visual

`edgework-anime.png` is an original AI-generated opening illustration created
for this project with the imagegen tool. It depicts the Violet costume in a
cinematic sports-anime direction. It is not artwork from Bones, MAPPA, or an
existing series. The file ships locally with the game; no external image host
or runtime generation is required.

The playable skater remains a procedural canvas character with cel shading,
ink outlines and directional facial features, rather than an animated version
of this illustration.
